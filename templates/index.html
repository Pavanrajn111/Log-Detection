          LIVE DEMO SCRIPT
          Sysmon Sentinel Presentation Guide
        

        
      

      

        

          Follow these 8 steps during your hackathon presentation to showcase live Windows Sysmon telemetry:
        


        

          
1

          

            
Start Flask Locally

            
Open an Administrator PowerShell / CMD prompt and run python app.py. The server strictly binds to http://127.0.0.1:5000.

          

        


        

          
2

          

            
Open Dashboard in Browser

            
Open http://127.0.0.1:5000. Note the Connected indicator, Sysmon64 Active badge, and that internal collector queries (wevtutil) are automatically filtered out.

          

        


        

          
3

          

            
Tour Summary Cards & Activity Timeline

            
Highlight live counts of Total Events, Process Creates (ID 1), Network (ID 3), and File Creates (ID 11). The SVG chart displays live temporal distribution.

          

        


        

          
4

          

            
Trigger Live Event: Open Notepad

            
Press Win + R, type notepad.exe, and press Enter. Sysmon immediately detects process creation.

          

        


        

          
5

          

            
Watch Auto-Refresh

            
Within 5 seconds (or click Refresh), observe the new Event ID 1 row appear at the very top of the feed with an emerald badge and clean process name.

          

        


        

          
6

          

            
Inspect Event Details

            
Click the notepad.exe event row or Inspect. Show the hierarchy (explorer.exe → notepad.exe), command line, and SHA256 hashes with 1-click copy.

          

        


        

          
7

          

            
Demonstrate Search & Filters

            
Type notepad into the search box to instantly isolate the event, or click the ID 1: Process filter pill.

          

        


        

          
8

          

            
Trigger File Create or Network / DNS

            
Save a file from Notepad, or run ping google.com in CMD to observe File Created (ID 11), DNS Query (ID 22), and Network Connection (ID 3) streaming live into the feed.
